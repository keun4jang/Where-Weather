# Internationalization

Powered by **i18next** + **react-i18next** with browser language detection.

## Supported languages

`en`, `ko`, `ja`, `zh-CN`, `es`, `fr`, `de`, `pt-BR`, `vi`, `id`, `ar` (RTL), `hi`.

The canonical list lives in `src/i18n/index.ts` (`SUPPORTED_LANGUAGES`). The
language switcher in the header is always visible.

## Files

- `src/i18n/index.ts` — init, detection (localStorage → navigator → htmlTag),
  RTL handling (`applyDocumentLanguage` sets `<html dir>` and `lang`).
- `src/i18n/locales/<code>.json` — one file per language.

## Rules

1. `en.json` is the source of truth. Every other locale must contain the **same
   keys** (English values are used as a safe fallback for untranslated strings).
2. Add new strings to `en.json` first, then translate.
3. Use interpolation (`{{name}}`) rather than string concatenation.
4. Never hard-code user-facing text in components — always `t('some.key')`.

## RTL

Arabic sets `dir="rtl"` on `<html>`. Tailwind logical spacing and fl\-based
layouts handle mirroring; verify new components in Arabic.

## Detection & persistence

The chosen language is cached in `localStorage` under `ww:lang` and restored on
next load.
