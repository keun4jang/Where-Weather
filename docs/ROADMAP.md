# Roadmap

This is an MVP. Directional ideas, not commitments.

## Near term (0.2.x)

- Add a third free provider (e.g. weather.gov for US) to strengthen fusion.
- Saved/favorite locations with quick switching.
- Daily (multi-day) forecast view in addition to hourly.
- Per-provider trust weighting in the fusion engine.
- Severe-weather alerts where freely available.

## Medium term

- Richer "disputed" UX explaining *which* metric disagrees and by how much.
- Installable onboarding + offline-first improvements (background sync).
- More granular air-quality guidance per pollutant and sensitive groups.
- Locale-aware unit defaults (imperial for en-US, metric elsewhere).

## Longer term

- Optional, self-hostable proxy bundle for providers needing server-side headers.
- Accessibility audit (screen reader flows, reduced motion, contrast themes).
- Community translations workflow and missing-key linting in CI.

## Non-goals

- Paid APIs, ads, accounts, or any server that stores user data.
